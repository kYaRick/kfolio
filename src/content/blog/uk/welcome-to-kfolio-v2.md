# Перезапуск kfolio: Шлях до другої версії

Коли я створював першу версію `kfolio`, моєю головною метою був експеримент із Blazor WebAssembly та можливостями .NET у браузері. Це був корисний полігон для випробування C# на стороні клієнта.

Проте для персонального портфоліо та регулярних інженерних нотаток швидкість оновлень і простота написання контенту мають вирішальне значення.

## Основні причини міграції

1. **Контент у чистому Markdown:** Оновлювати резюме та публікувати нові дописи у форматі Markdown значно зручніше й швидше, ніж правити C# структури.
2. **Швидкість та надійність SSG:** Astro не перевантажує клієнт зайвим JavaScript, генерує надшвидкий статичний HTML та ідеально підходить для GitHub Pages.
3. **Естетика терміналу:** Сучасні CSS-змінні дозволили відтворити чистий термінальний стиль, гнучкі теми та інтерактивні фонові анімації.

```bash
kfolio > astro build
[build] Збірка завершена за 1.37с!
[status] Усі сторінки згенеровано успішно.
```
